# 👨‍🍳 Chef Claude (AI Recipe Generator)

Welcome to **Chef Claude**, a React application that turns your leftover ingredients into delicious, AI-generated recipes! Simply type in the ingredients you have on hand, and let the AI do the thinking.

## 🍽️ Features

- **Ingredient Tracker**: Add the ingredients you currently have in your kitchen.
- **AI-Powered Recipes**: Send your ingredients to the backend, where an AI model generates a specific, step-by-step recipe for you.
- **Beautiful Markdown Output**: The recipe is generated in Markdown and beautifully rendered automatically via `react-markdown` and Tailwind Typography.
- **Secure Backend Integration**: API keys are securely kept server-side, preventing exposure to the browser.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS v4, `@tailwindcss/typography`
- **Markdown Parsing**: `react-markdown`
- **Backend**: Express.js proxy server
- **AI Integration**: Google AI Studio (Gemini 2.5 / 2.0 Models)

## 🏗️ Architecture & How It Works

This project is built with security and aesthetics in mind. Here's a breakdown of the core architectural decisions:

### Application Flow
1. **User Input:** The user adds ingredients to the `MainComponent.jsx` input field.
2. **State Management:** The ingredients are held in a React `useState` array.
3. **API Request:** When the user clicks "Get a recipe", a `fetch` request is made to `/api/recipe` with the ingredients.
4. **Backend Proxy:** The Vite proxy forwards this request to a local Express.js server (`server.js`). The Express server securely attaches the Google AI API key, executes the call to the Gemini model, and returns a Markdown response.
5. **Display & Styling:** The React frontend receives the Markdown string and uses `react-markdown` and the Tailwind Typography plugin to render it beautifully in `ClaudeRecipe.jsx`.

### Secure API Integrations
A core goal of this project is to keep the API key completely safe.
- **The Problem:** Exposing API keys in frontend code (like Vite's `VITE_API_KEY`) allows anyone checking the network tab of their browser to steal it.
- **The Solution:** We use a lightweight Express.js server that acts as a middleman. The frontend talks to the middleman, and the middleman securely talks to the AI provider.

### Beautiful Markdown Rendering
AI models (like Gemini) return raw Markdown text (e.g., `# Recipe`, `* Ingredient`).
- **`react-markdown`:** Parses the raw markdown string sent by the AI and translates it directly into React components.
- **`@tailwindcss/typography`:** By default, Tailwind CSS strips away all standard browser styling. To fix this, we use the Tailwind Typography plugin (`prose` classes). It automatically layers gorgeous, pre-calculated typography scales, line-heights, and spacing margins onto the raw unstyled HTML generated by the markdown parser.

## 🚀 Getting Started

Follow these steps to set up the project locally.

### 1) Navigate to the Application Directory
The main application code is inside the `chef-claude` folder.
```bash
cd chef-claude
```

### 2) Create Local Environment File
You need an API key to allow the application to generate recipes. 
Create a `.env.local` file in the `chef-claude` directory and add your keys:

```bash
GOOGLE_AI_API_KEY=your_real_key_here
GOOGLE_AI_MODEL=gemini-2.0-flash
PORT=3001
```

### 3) Install Dependencies
```bash
npm install
```

### 4) Run Both Frontend and Backend
We use `concurrently` to run the React development server and the backend Express server at the same time:

```bash
npm run dev:all
```

### 5) Key Safety Checklist
- 🚫 **Never** commit your `.env.local` file to GitHub.
- ✅ The backend handles all API requests. The frontend only talks to the local `/api/recipe` proxy.

## 📂 Folder Structure Overview

Inside the `chef-claude` directory:
- `src/MainComponent.jsx`: The primary smart component that manages ingredient state and makes the fetch call to the backend.
- `src/IngredientList.jsx`: A presentational component mapping over the ingredients list.
- `src/ClaudeRecipe.jsx`: The presentational component wrapping `<ReactMarkdown>` to convert the backend response text into UI.
- `server.js`: The minimal Express wrapper functioning as our secure proxy for the Google AI Studio request.
